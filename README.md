# Deep Code Client

Веб-приложение для просмотра пользователей и постов из API [GoRest](https://gorest.co.in/).
Позволяет авторизоваться с помощью токена, просматривать списки пользователей и постов с пагинацией, а также переходить к детальным карточкам с комментариями.

## Описание работы

Приложение предоставляет интерфейс для работы с публичным API GoRest:

1. **Авторизация** - пользователь вводит access token для доступа к API
2. **Выбор режима** - переключение между просмотром пользователей и постов
3. **Таблицы с пагинацией** - отображение данных с возможностью настройки количества записей (10/25/50) и навигацией по страницам
4. **Детальные карточки** - при клике на строку открывается карточка с полной информацией:
   - Для пользователя: id, имя, email, пол, статус
   - Для поста: id, заголовок, содержание и все комментарии
5. **Возврат к списку** - кнопка возврата на главную страницу

## Стэк технологий + FSD

### Основной стек

- **React 19** - библиотека для построения UI
- **TypeScript** - типизация кода
- **Vite** - сборщик проекта
- **React Router v7** - маршрутизация
- **TanStack Query** - управление серверным состоянием и кэшированием
- **Axios** - HTTP-клиент для запросов к API
- **Consta UI Kit** - компоненты интерфейса

**Принципы FSD в проекте:**

- **Слабая связанность** - слои зависят только от нижележащих
- **Переиспользование** - shared-компоненты используются во всем проекте
- **Типобезопасность** - строгая типизация на всех уровнях

## Инструкция для запуска

### Требования

- Node.js 20 или выше
- npm 10+ или yarn 1.22+
- Современный браузер (Яндекс.Браузер, Edge, Chrome)

### Установка и запуск

1. **Клонируйте репозиторий**

```bash
git clone https://github.com/rifatikkkk/deepcode.git
cd client
```

2. **Установите зависимости**

```bash
npm install
# или
yarn install
```

3. **Настройте переменные окружения**
   Создайте файл .env в корне папке `client` и добавьте переменную `VITE_API_URL`. Пример:

```bash
VITE_API_URL=https://gorest.co.in/public/v2
```

4. **Запустите приложение в режиме разработки**

```bash
npm run dev
# или
yarn dev
```

5. **Откройте приложение в браузере**

Перейдите по адресу: http://localhost:5173
